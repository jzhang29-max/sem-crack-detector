# HEADLESS ON PURPOSE. This repo uses exactly one OpenCV function -- cv2.polylines, at
# code/detect_cracks.py:824 and interior_active_learning/code/interior_candidates.py:546 --
# and never opens a window. The plain `opencv-python` wheel is linked against Qt: its
# cv2.abi3.so has DT_NEEDED entries for libQt5Core/Gui/Widgets, and those need libGL.so.1 and
# libglib-2.0.so.0 from the host, which manylinux does not vendor. On a headless Linux box --
# a slim container, an Ubuntu Server minimal install, a cluster node -- `import cv2` therefore
# dies with "libGL.so.1: cannot open shared object file", and because interior_candidates.py
# imports cv2 at module level and paint_server.py imports interior_candidates, the app cannot
# even start. This was invisible on the machine it was built on, where opencv-python-headless
# happened to be installed as a transitive dependency and won the import.
opencv-python-headless>=4.12
tifffile>=2026.7

# ---- SAM 2: installed, but OPT-IN at runtime ----
# SAM 2 boundary refinement is available via --sam2 refine and is NOT on by default. On
# adjudicated pixels it beats the bare pipeline on all four metrics (f1 0.676 vs 0.638,
# specificity 0.569 vs 0.460), but on the whole frame it fragments the mask: connected
# components +83%, skeleton length +97%, and it claims 54,217 px of new area outside the
# detector's own candidates. It was briefly the default and that was reverted. Reproduce with
# interior_active_learning/code/experiments/fragmentation_check.py.
#
# These stay in requirements because the test suite exercises the SAM 2 path and because
# --sam2 refine should work without a second install step. If you never opt in, they are
# 0.63 GB you did not need; remove them and the pipeline is unaffected.
#
# Cost, measured rather than guessed: 0.63 GB installed here (torch 0.52, transformers 0.10,
# torchvision 0.01), plus a ~150 MB checkpoint fetched from HuggingFace on first detection and
# cached after. An earlier version of this file said "~2.5 GB plus a ~2.4 GB checkpoint" --
# that was SAM 1's ViT-Huge and is not what runs now.
#
# If these are absent and you DO opt in, the pipeline degrades to the bare detector, records
# detector.sam2_mode = "unavailable" with the reason in every CSV's sidecar, and does not
# raise.
torch>=2.2
# FLOOR SET TO WHAT IS VERIFIED, not to the oldest that might work. Sam2Model arrived in
# transformers recently, and a looser floor lets pip resolve a version without it -- which
# would not error, it would silently fall back to the bare detector and quietly change every
# number the README attributes to the default. A too-tight floor costs a larger download; a
# too-loose one costs a wrong result, so this errs tight and says why.
transformers>=5.15
torchvision>=0.17
