# Lower bounds only, so a clone gets current releases. The versions this was last
# built and tested against are recorded below -- worth pinning if you need to
# reproduce a published number exactly, because the models are pickled sklearn
# estimators and sklearn warns (loudly, if you do not silence it) when the version
# that loads a model differs from the one that saved it. `python3
# code/resave_models.py` reconciles the shipped models with your environment.
#   tested: numpy 2.5.2, pandas 3.0.5, scikit-learn 1.9.0, scikit-image 0.26.0,
#           scipy 1.18.0, Pillow 12.3.0, joblib 1.5.3, Flask 3.1.3,
#           tifffile 2026.8.16, Python 3.12
numpy>=2.3
pandas>=2.2
# Pinned with a CEILING on purpose. The shipped bundles are pickled at 1.9.0, and
# every module calls warnings.filterwarnings("ignore"), which swallows sklearn's
# InconsistentVersionWarning -- so a clone made after 1.10 ships would silently
# unpickle a 1.9.0 estimator and could report different numbers from the ones in
# docs/MODEL_VALIDATION_BENCHMARK.md with nothing on screen saying so.
# /api/pipeline_info reports sklearn_built vs sklearn_running; re-save with
# python3 code/resave_models.py after a deliberate upgrade.

# ---- SAM 2: REQUIRED, because it is the default detector ----
# run_unified_pipeline applies SAM 2 boundary refinement to every accepted candidate by
# default. Measured on the ten both-class frames it beats the bare pipeline on all four
# metrics (f1 0.676 vs 0.638, recall 0.561 vs 0.534, specificity 0.569 vs 0.460, precision
# 0.976 vs 0.970), so it is not optional garnish and these are not optional installs.
#
# Cost, measured rather than guessed: 0.63 GB installed here (torch 0.52, transformers 0.10,
# torchvision 0.01), plus a ~150 MB checkpoint fetched from HuggingFace on first detection and
# cached after. An earlier version of this file said "~2.5 GB plus a ~2.4 GB checkpoint" --
# that was SAM 1's ViT-Huge and is not what runs now.
#
# If these are absent the pipeline degrades to the bare detector, records
# detector.sam2_mode = "unavailable" with the reason in every CSV's sidecar, and does not
# raise. So the tool still works without them; it just is not the detector the README
# describes. Set SEMCRACK_SAM2= or pass --sam2 off to choose that deliberately.
torch>=2.2
# FLOOR SET TO WHAT IS VERIFIED, not to the oldest that might work. Sam2Model arrived in
# transformers recently, and a looser floor lets pip resolve a version without it -- which
# would not error, it would silently fall back to the bare detector and quietly change every
# number the README attributes to the default. A too-tight floor costs a larger download; a
# too-loose one costs a wrong result, so this errs tight and says why.
transformers>=5.15
torchvision>=0.17
